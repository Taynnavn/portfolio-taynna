R02 · Registro de Aplicação

document

Sistematizar   Página/seção alvo: css/style.css (nível de projeto)

Problema observado

O CSS tinha tokens de cor e fonte definidos em :root, mas nenhum documento explicava o que cada um significava ou onde deveria ser usado.

Hipótese de melhoria

Documentar os tokens existentes tornaria mais fácil identificar inconsistências, como cores usadas em contextos onde falhavam no contraste.

Comando escolhido

/impeccable document

Prompt / orientação complementar

Atue como o comando /impeccable document. Leia o css/style.css do projeto e gere uma lista de todos os tokens de cor, fonte e transição definidos em :root, com uma frase sobre o uso pretendido de cada um.

Resultado produzido

Lista de 8 tokens de cor e 2 de fonte documentada. Essa lista expôs que não existia nenhuma variante de cor pensada especificamente para uso em texto — todas as cores da marca eram genéricas, usadas tanto em fundo quanto em texto, o que causou os problemas de contraste encontrados no audit (R05).
